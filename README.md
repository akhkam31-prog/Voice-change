# Voice Changer

Android-приложение с эффектами голоса. Собирается в APK через GitHub Actions.

## Эффекты
- Noise reduction (фильтр 80 Гц + шумовой гейт)
- Pitch shifting (высота, полутоны)
- Formant shifting (тембр, высота сохраняется)
- Mild distortion (мультяшность)
- Robot (ring modulator)
- Low-pass (как через капюшон)
- Band-pass (из-под ткани)
- Bass boost, Treble reduction
- Эхо, громкость, пресеты

## Как получить APK
1. Создай репозиторий на GitHub и загрузи все файлы проекта, включая папку `.github`.
2. Открой вкладку Actions → Build APK. Сборка запускается при каждом push, можно и вручную через Run workflow.
3. Когда появится зелёная галочка, открой запуск и скачай artifact `VoiceChanger-debug`.
4. Внутри архива `app-debug.apk`. Установи на телефон, разрешив установку из этого источника.

## Важно
- Используй наушники, иначе будет петля обратной связи.
- Задержка около 50 мс.
- Приложение останавливается, когда уходит с экрана (ограничение Android на фоновый микрофон).
- Шумодав — фильтр и гейт, а не нейросеть.
